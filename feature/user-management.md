# User Management

## Objective

To understand how users can be managed in an IT helpdesk system.

## What Is User Management?

User management is the process of creating, maintaining, and managing user accounts within a helpdesk system.

A helpdesk system needs user information so that support requests can be associated with the correct person.

## User Information

A basic user record may contain:

- User ID
- Name
- Email
- Department
- Role
- Account status
- Date created

Example:

User ID: U-001

Name: Ahmed Khan

Email: ahmed@example.com

Department: Administration

Role: Staff

Status: Active

## User Roles

A helpdesk system may have different user roles.

### End User

An end user can:

- Create support tickets
- View their own tickets
- Add information to their tickets
- Check ticket status

### Technician

A technician can:

- View assigned tickets
- Investigate problems
- Update tickets
- Add troubleshooting notes
- Change ticket status
- Record resolutions

### Administrator

An administrator may be responsible for:

- Managing users
- Managing technicians
- Managing categories
- Managing priorities
- Managing system settings
- Monitoring helpdesk activity

The exact permissions should depend on the organization's requirements.

## Creating a User

A basic user creation process may include:

1. Open the user management section.
2. Select Add User.
3. Enter the user's name.
4. Enter the email address.
5. Select the department.
6. Assign an appropriate role.
7. Save the user record.

## Updating User Information

User information may need to be updated when:

- A user changes department.
- A user's email changes.
- A user's role changes.
- An account needs to be disabled.
- Incorrect information needs to be corrected.

Only authorized staff should modify user information.

## User and Ticket Relationship

A user can create multiple support tickets.

Example:

User:
Ahmed Khan

Tickets:

HD-001 - Printer problem

HD-004 - No internet connection

HD-009 - Software installation request

This creates a one-to-many relationship between users and tickets.

One user can have many tickets.

## Account Status

A user account may have different statuses such as:

- Active
- Inactive
- Disabled

An inactive or disabled account should not be given unnecessary access to the helpdesk system.

## Security Considerations

User information should be protected.

Important practices include:

- Use authentication.
- Give users only the required permissions.
- Protect personal information.
- Do not store passwords in plain text.
- Do not share account credentials.
- Disable accounts when they are no longer required.
- Restrict administrative functions to authorized users.

## Example Scenario

### Problem

A new teacher joins a school and needs access to the IT helpdesk system.

### Process

1. Create a user account.
2. Enter the teacher's information.
3. Assign the appropriate user role.
4. Provide the required login method.
5. Confirm that the user can create a support ticket.

### Result

The teacher can submit and track their IT support requests.
