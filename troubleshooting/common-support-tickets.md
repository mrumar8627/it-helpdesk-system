# Common IT Support Tickets

## Objective

To identify common IT support problems and understand basic troubleshooting approaches.

## 1. Computer Not Turning On

### Problem

A user reports that the computer does not turn on.

### Basic Checks

- Check the power cable.
- Check the power outlet.
- Check the power button.
- Check monitor power.
- Check for visible hardware issues.
- Test another power cable when appropriate.

### Possible Causes

- Power connection problem
- Faulty power cable
- Power supply problem
- Hardware failure

### Documentation

Record the checks performed and the result in the support ticket.

---

## 2. Slow Computer

### Problem

A user reports that the computer is running slowly.

### Basic Checks

- Open Task Manager.
- Check CPU usage.
- Check memory usage.
- Check disk usage.
- Check running applications.
- Check available storage.
- Review startup applications.
- Check for pending Windows updates.

### Possible Causes

- High memory usage
- Too many applications running
- Limited storage space
- Background processes
- Software-related problems

### Documentation

Record the findings and actions taken.

---

## 3. No Internet Connection

### Problem

A user cannot access the internet.

### Basic Checks

- Check the network cable.
- Check Wi-Fi connection.
- Check network adapter status.
- Run `ipconfig`.
- Test the local network using `ping`.
- Check IP configuration.
- Test another website or network resource.

### Possible Causes

- Disconnected cable
- Wi-Fi connection problem
- Incorrect IP configuration
- Network adapter problem
- Network service problem

### Documentation

Record the tests performed and the results.

---

## 4. Printer Not Working

### Problem

A user cannot print a document.

### Basic Checks

- Check printer power.
- Check cables or network connection.
- Check paper and ink or toner.
- Check printer status in Windows.
- Check the selected printer.
- Check the print queue.
- Print a test page.

### Possible Causes

- Printer disconnected
- Print queue problem
- Incorrect printer selected
- Driver problem
- Hardware problem

### Documentation

Record the cause if identified and the solution applied.

---

## 5. Keyboard or Mouse Not Working

### Problem

A keyboard or mouse is not responding.

### Basic Checks

- Check the USB connection.
- Try another USB port.
- Check wireless batteries if applicable.
- Reconnect the device.
- Test another keyboard or mouse.
- Check Device Manager if required.

### Possible Causes

- Loose connection
- Faulty USB port
- Low battery
- Device failure
- Driver problem

---

## 6. Software Not Opening

### Problem

An application does not start correctly.

### Basic Checks

- Restart the application.
- Restart the computer.
- Check for error messages.
- Check available storage.
- Check for application updates.
- Check Windows updates.
- Review Task Manager if the application is already running.

### Possible Causes

- Application error
- Corrupted installation
- Missing update
- Background process
- System resource limitation

---

## 7. Software Installation Request

### Problem

A user needs an application installed on a computer.

### Basic Checks

- Confirm the required software.
- Check whether installation is authorized.
- Check system requirements.
- Check available storage.
- Use a trusted installation source.
- Install the software.
- Test the application.

### Security Consideration

Software should only be installed from trusted sources and according to organizational policies.

---

## 8. Windows Update Problem

### Problem

Windows Update is not installing successfully.

### Basic Checks

- Check internet connection.
- Open Windows Update.
- Review the error message.
- Check available storage.
- Restart the computer.
- Try checking for updates again.

### Documentation

Record the error message and troubleshooting steps.

---

## 9. Shared Folder Access Problem

### Problem

A user cannot access a shared folder.

### Basic Checks

- Check network connection.
- Verify the computer name.
- Check the network path.
- Confirm that the folder is shared.
- Check sharing permissions.
- Check NTFS permissions.

### Example

Network path:

`\\ComputerName\SharedFolder`

### Possible Causes

- Network connection problem
- Incorrect network path
- Sharing configuration problem
- Insufficient permissions

---

## Troubleshooting Approach

A structured approach can be used for most support tickets:

1. Identify the problem.
2. Collect information.
3. Perform basic checks.
4. Identify a possible cause.
5. Apply an appropriate solution.
6. Test the solution.
7. Confirm the result.
8. Document the troubleshooting process.
9. Close or escalate the ticket.

## Important Support Practices

An IT support technician should:

- Ask clear questions.
- Start with simple checks.
- Avoid unnecessary system changes.
- Protect user data.
- Follow organizational procedures.
- Document important actions.
- Verify the solution.
- Escalate complex problems when necessary.
